# LeisureSocial – release notes

For editors. Newest first.

## 2.0.2 – put in the LMG Updater list 25 Nov 2026

### New
- Nothing new in the plugin. This is exactly the version that runs on traveltalk.dk, now offered to the other sites through LMG Updater so all sites run the same version.

### What you do differently
- On each site still on 2.0.1: press **Update all now** in the yellow LMG notice. LeisureSocial is a one-file plugin; the Updater keeps a copy of the old file (Tools → LMG Updates → "Put this version back").

### Good to know
- The copy was taken from traveltalk.dk with "Download a copy" on 25 Nov 2026. Tested on a test WordPress: 2.0.1 → 2.0.2 installed and stayed active. Not tested on the live sites.

### Older content
- Not affected. The share log on each post stays as it is.
